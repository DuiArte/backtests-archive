# Backtests Archive

**A frozen, dated record of final backtest reports — one immutable report per published strategy.**

![status](https://img.shields.io/badge/status-archived-blue) ![license](https://img.shields.io/badge/license-CC--BY--NC--4.0-green) ![updated](https://img.shields.io/badge/updated-2026--06-lightgrey)

---

This repository is the evidence locker. Each report is a final, dated summary for a
strategy that is *already public* elsewhere in the family. Reports are immutable:
corrections are added as new dated files, never edited in place.

## Layout

```
reports/<strategy>/<YYYY-MM>_final_report.md
index.md     a table of every archived report
```

## What's deliberately *not* here

Raw trade logs, parameter-search grids, intermediate (non-final) backtests, and any
report for a strategy that is not itself public. Same redaction tier as the source
strategy repos — ratios and verdicts, never notional. See [`_MANIFEST.md`](_MANIFEST.md).
